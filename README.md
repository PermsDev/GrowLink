**GrowLink — Connecting and Protecting Growtopia Communities**

GrowLink is a Discord bot designed to simplify GrowID verification, improve community management, and enhance security for Growtopia communities.

**Key Features**

- **GrowID Introduction:** Let members submit their GrowID through an interactive Introduction panel.
- **Automated Role Assignment:** Assign roles automatically after members complete the Introduction process.
- **Display Name Management:** Update member display names using their GrowID.
- **Cross-Server Synchronization:** Synchronize GrowID data across participating servers using GrowLink.
- **Phishing Image Detection:** Detect potentially malicious images using image analysis and similarity scoring, with exact image matches receiving the highest detection score.
- **Moderation and Review:** Forward suspicious images for review and support moderation actions based on detection results.
- **Community Promotion:** Provide tools for promoting Growtopia items and worlds across participating communities.
- **Interactive Help System:** Access command documentation in multiple languages through Discord Components V2.

GrowLink brings together community management, cross-server connectivity, phishing detection, and moderation tools to help Growtopia communities operate more efficiently and securely.
